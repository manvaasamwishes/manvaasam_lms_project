# Manvaasam LMS Project

> **From College to Corporate** — Learning Management System (LMS) & Administration Gateway for Manvaasam.

---

## 🍃 Overview

Manvaasam LMS is a high-performance Learning Management System built for students and institution administrators.

- **Student Portal (`/login`, `/signup`)**: Dual-mode interactive authentication card with seamless diagonal green ribbon transition, auroramorphic background mesh, and Poppins typography.
- **Admin Portal (`/admin/login`)**: Executive dual-zone command portal featuring deep forest atmospheric depth, executive branding, and security controls.

---

## 🛠️ Tech Stack

- **Framework**: React 19 + TypeScript + Vite
- **Styling**: Tailwind CSS
- **Routing**: React Router DOM v7
- **Form & Validation**: React Hook Form + Zod (`@hookform/resolvers`)
- **Animations**: Framer Motion
- **Iconography**: Lucide React

---

## 🚀 Quick Start

1. **Clone the repository**:
   ```bash
   git clone https://github.com/manvaasamwishes/manvaasam_lms_project.git
   cd manvaasam_lms_project
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start local development server**:
   ```bash
   npm run dev
   ```

4. **Build for production**:
   ```bash
   npm run build
   ```

---

## 🔒 Security & Architecture

- **Student Route**: `http://localhost:5173/login`
- **Admin Route**: `http://localhost:5173/admin/login`
- **Protected Routing**: Role-based access control architecture ready for PHP REST API authorization enforcement.
